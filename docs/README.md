# Documentation index

Start with [Current status](STATUS.md) for today’s state,
[User guide](USER_GUIDE.md) for installation and controls, or
[Architecture](architecture.md) for implementation.

The released macOS package and the separate Windows development branch have
different verification scopes. The Windows checkpoint and pinned links are in
[Current status](STATUS.md#windows-continuation).

Dated files are retained in place to preserve existing links, candidate hashes
and original verdicts. Their PASS/BLOCKED/NOT RUN statements describe the named
checkpoint. Earlier release-policy holds are superseded only where a later
decision explicitly records that change. JSON files are evidence, not new tests.

The catalogue below includes every document/evidence file in this directory.
File names are kept explicit so developers can locate the original record.
