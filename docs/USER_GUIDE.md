# FSTR Stretch 0.9.3-perf.1 — руководство пользователя

FSTR Stretch растягивает изображение, текст или другой плоский слой при
перемещении линий сетки. Эффект находится в группе **FSTR Effects**.

## Совместимость

Проверенная конфигурация: **After Effects 2025, версия 25.6x101**, macOS
**26.6.2**, Mac с Apple Silicon. Замеры выполнены на M1 Pro с 16 ГБ памяти.
Другие версии AE/macOS, Mac с Intel и Windows не проверены для этого выпуска.

Работа проверена на обычных плоских текстовых и растровых слоях, в том числе
с 3D-положением и камерой. Персональное 3D-преобразование отдельных символов,
все возможные HDR/OCIO-настройки и неквадратные пиксели не входят в этот
подтверждённый набор. Эффект работает на CPU; GPU-рендер отключён.

Номер скачиваемого пакета — **0.9.3-perf.1**. В About эффекта отображается
**0.9.3 Develop Build 2**: это ожидаемо, плагин при выпуске не пересобирался.

## Установка

1. Закройте After Effects и другие приложения Adobe, использующие плагины.
2. Скачайте ZIP со страницы [релиза 0.9.3-perf.1](https://github.com/ios3kov/ElasticGridFX/releases/tag/v0.9.3-perf.1).
   Имя файла — `FSTR-Stretch-0.9.3-perf.1-macOS-arm64-TEST.zip`.
   Слово TEST сохранено в имени уже опубликованного архива; текущий выпуск имеет
   статус Latest Release.
3. Распакуйте внешний ZIP, затем находящийся внутри `FSTR Stretch.plugin.zip`.
4. Если уже установлен FSTR Stretch, перенесите его резервную копию **за пределы
   всех папок плагинов Adobe**. Оставьте только одну активную копию эффекта.
5. Поместите целиком `FSTR Stretch.plugin` в папку
   `/Library/Application Support/Adobe/Common/Plug-ins/7.0/MediaCore/FSTR FX/`.
   Создайте `FSTR FX`, если её нет. Для записи macOS может запросить пароль
   администратора. Не переносите отдельно содержимое `.plugin`.
6. Запустите AE. Выберите слой и откройте
   **Effect → FSTR Effects → FSTR Stretch**. Эффект также можно найти поиском
   в панели **Effects & Presets**.

Плагин имеет подпись ad-hoc, без Developer ID и нотариализации. Этот выпуск
проверялся после скачивания с сохранённой карантинной меткой macOS. Если macOS
блокирует загрузку, сохраните текст сообщения и сообщите о проблеме; не отключайте
защиту системы и не удаляйте карантинную метку.

Внутренний README архива описывает прежний этап тестового выпуска. Эта инструкция
и текущая страница релиза определяют актуальную установку и статус.

## Быстрый старт

1. Создайте композицию и добавьте текст или изображение.
2. Выделите слой, примените FSTR Stretch и выберите эффект в **Effect Controls**.
3. Оставьте **Deformation Plane: Layer Plane**, **Columns: 4**, **Rows: 4**
   и **Render Quality: Final (Bicubic)**.
4. В окне композиции возьмитесь за внутреннюю вертикальную линию сетки
   и немного переместите её вправо. Соответствующий участок слоя растянется.
   Горизонтальные линии меняют растяжение по вертикали.
5. Нажмите **Cmd+Z**, чтобы отменить последнее изменение.

Сетка — элемент управления, она не должна появляться в итоговом рендере.
Чтобы видеть её, держите эффект выбранным и включите отображение элементов
управления слоя через **View → Show Layer Controls**.

## Основные настройки

| Настройка | Назначение |
|---|---|
| **Deformation Plane** | **Layer Plane** привязывает сетку к плоскости слоя. **Four Corners** задаёт область деформации четырьмя углами в 2D. |
| **Plane Top Left / Top Right / Bottom Right / Bottom Left** | Положение углов области в режиме Four Corners. Можно менять точечными настройками или угловыми ручками сетки. |
| **Reset Plane → Fit Layer** | Возвращает углы области Four Corners к границам слоя. Не является сбросом позиций внутренних линий. |
| **Columns / Rows** | Задают число колонок и строк. Выберите их перед анимацией; в этой версии это настройки структуры сетки без новых ключевых кадров. |
| **Grid Positions** | Хранит положения линий. Используйте секундомер этого параметра для анимации сетки. Пустая область значения рядом с названием — нормальное отображение. |
| **Tension Radius** | Радиус влияния перемещаемой линии на соседние, в шагах сетки. Меньше — более локальная деформация. |
| **Falloff** | Форма затухания влияния: Smoothstep, Gaussian, Linear. Smoothstep (Legacy) оставлен для старых проектов. |
| **Elasticity Strength** | Сила смещения соседних линий при перетаскивании; начните со значения 100%. |
| **Min Line Spacing** | Минимальное расстояние между соседними линиями. Уменьшите, если требуется более сильное сжатие. |
| **Stretch Easing** | Смягчает переходы растяжения возле границ ячеек. При 0% используется исходный линейный переход. |
| **Easing Distance** | Размер зоны смягчения возле границ ячеек; действует совместно со Stretch Easing. |
| **Wave Amplitude** | Величина волнового смещения. Значение 0 отключает волну. Отдельного видимого переключателя включения нет. |
| **Wave Frequency** | Частота волны по сетке. |
| **Wave Phase** | Сдвиг фазы в градусах. Можно анимировать ключевыми кадрами. |
| **Wave Speed** | Автоматическое изменение фазы во времени. 0 останавливает его; отрицательное значение меняет направление. |
| **Wave Axis** | Волна по обеим осям (Both), колонкам (Columns Only) или строкам (Rows Only). |
| **Edge Behavior** | Выбор пикселей у края источника: Clamp удерживает край, Wrap повторяет, Mirror отражает. |
| **Render Quality** | Final (Bicubic) — итоговое качество. Preview (Bilinear) — отдельный режим с другой интерполяцией. Оптимизация этого выпуска не требует перехода на Preview. |

## Типовые сценарии

### Анимация растяжения

1. Задайте Columns и Rows до постановки ключей.
2. Установите время начала, включите секундомер **Grid Positions**.
3. Перейдите к следующему моменту и передвиньте внутреннюю линию сетки.
4. Запустите Preview: положения сетки меняются между ключами.
5. Сохраните проект. При переносе старого проекта сначала проверьте его копию.

### Волна без ручного перемещения сетки

1. Увеличьте **Wave Amplitude**, например до 2%.
2. Оставьте **Wave Frequency: 1** и выберите нужную **Wave Axis**.
3. Задайте ненулевую **Wave Speed**, например 0.5, и запустите Preview.
4. Для точного управления временем поставьте Wave Speed в 0 и анимируйте Wave Phase.
5. Для отключения волны верните Wave Amplitude в 0.

### Деформация области в перспективе

1. Используйте 2D-слой и выберите **Four Corners**.
2. Расставьте четыре угла вокруг нужной области, сохраняя простой выпуклый
   четырёхугольник; не пересекайте противоположные стороны.
3. Передвиньте внутреннюю линию сетки и оцените растяжение.
4. Для возвращения области к слою нажмите **Fit Layer**.

Four Corners задаёт область деформации; он не заменяет эффект Corner Pin,
перемещающий всё изображение в четырёхугольник. В 3D используется Layer Plane,
угловые настройки недоступны, а сохранённые значения Four Corners остаются в проекте.

### Итоговый рендер

1. Выберите **Final (Bicubic)**.
2. Для просмотра полной детализации установите разрешение композиции и Preview
   в **Full** средствами AE.
3. Проверьте нужный участок анимации, затем используйте обычный Render Queue.

Выбор Full в окне композиции и настройки разрешения панели Preview различаются:
проверьте оба. Скорость зависит от сцены, разрешения и настроек AE; опубликованные
замеры не обещают одинаковое ускорение для каждого проекта.

## Типичные проблемы

**Эффекта нет в списке.** Проверьте, что установлен весь пакет `.plugin`, а не ZIP,
что используется Apple Silicon и AE 25.6, затем полностью перезапустите AE.
Уберите дубликаты FSTR Stretch из других папок плагинов Adobe.

**Сетки не видно.** Выберите слой и сам эффект, включите Show Layer Controls.
Постоянное отображение сетки при снятом выделении в этой версии не реализовано.
Для обычного 3D-текста используйте окно композиции; отдельные режимы Layer viewer
не поддерживают управление спроецированной текстовой сеткой.

**Перетаскивание почти не меняет изображение.** Используйте слой с заметными
деталями, двигайте внутреннюю линию, проверьте ограничение Min Line Spacing и
геометрию Four Corners. Одноцветный участок может скрывать результат растяжения.

**Волна не движется.** Проверьте Wave Amplitude > 0 и Wave Speed ≠ 0 либо ключи
Wave Phase. Обычный статичный Grid Positions сам по себе не запускает волну.

**В старом проекте анимированы Columns/Rows.** Не удаляйте эти ключи в оригинале.
Пользователь подтвердил работу одного старого проекта, но проверка всех вариантов
миграции не выполнялась. Проверяйте вывод и сохранение на копии своего проекта.

**AE завершился аварийно при рендере.** Для одного контрольного запуска MFR
зафиксирован редкий сбой; он не повторился в шести повторных запусках, причина
не установлена. Сохраните версию AE, настройки Render Queue/MFR, момент сбоя
и отчёт macOS. В [issue #21](https://github.com/ios3kov/ElasticGridFX/issues/21)
сохранена история. Для нового сбоя откройте issue с шагами воспроизведения;
проект и материалы прикладывайте только если их можно публиковать.

## Обновление и откат

1. Сохраните проекты и закройте приложения Adobe.
2. Перенесите предыдущий `.plugin` за пределы всех папок плагинов Adobe.
3. Установите новую версию по инструкции выше и перезапустите AE.
4. Откройте копию рабочего проекта и проверьте изображение, анимацию и сохранение.
5. Для отката закройте приложения Adobe, уберите новый `.plugin` и верните
   резервную копию. Не оставляйте две активные версии одновременно.

Если у вас уже стоит проверенный ускоренный **0.9.3 Develop Build 2** из этого
выпуска, повторная установка для обновления документации не нужна.

## Удаление

Закройте приложения Adobe и удалите установленный `FSTR Stretch.plugin`
из папки MediaCore/FSTR FX. После перезапуска эффект исчезнет из списка.
В проектах, где он использовался, AE сообщит об отсутствующем эффекте.
Сначала сохраните резервные копии таких проектов.
